# 阶段 0.4 候选规则（实验用，正式格式在 M2 定义）
#
# 格式：id | 层 | 类别 | 风险 | 模式 [& 条件]...
#   层：system 系统位置 / generic 通用结构 / devtools 开发与 AI 工具 / apps 常用软件抽样
#   风险：safe 会自动重建 / low 需重新下载 / medium 丢历史或登录态 / high 丢用户数据 / never 不能删 / guide 只能用官方工具处理
#   模式：
#     dir:<glob>    目录完整路径匹配，命中后整棵子树都归这条规则，不再往下找
#     file:<glob>   文件完整路径匹配
#     under:<glob>  兜底：这个目录下没被更具体的规则认领的部分都归它（继续往下找，找不到再回来兜底）
#   glob：* 匹配一段内任意字符，** 匹配任意层目录，{a,b} 任选其一，大小写不敏感
#   条件：has:<名称>（目录里有这个子项）、sibling:<名称>（同级有这个子项）、notpath:<glob>（路径不能匹配）
#   路径令牌：%USERPROFILE% 展开为 C:\Users\*（所有用户），其余同理
# 顺序有意义：同一节点按文件顺序匹配第一条。
