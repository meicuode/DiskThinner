# DiskThinner 0.1.0

第一个版本：分析 C 盘哪里大、哪里在涨、是谁的、能不能删，确认后清理。只在本机运行，不联网。

## 下载哪个

| 文件 | 说明 |
|---|---|
| `DiskThinner-0.1.0-win-x64.zip`（1.6 MB） | 需要先装 [.NET 10 桌面运行库（x64）](https://dotnet.microsoft.com/download/dotnet/10.0)。没装时双击会提示去下载 |
| `DiskThinner-0.1.0-win-x64-selfcontained.zip`（44.5 MB） | 单个 exe，不需要装运行库 |

解压到任意目录，运行 `DiskThinner.exe`。支持 Windows 10 / 11 64 位。

## 功能

- 扫描：管理员身份下直接读取 NTFS 主文件表（MFT），C 盘几秒扫完；普通权限下逐个目录遍历。
- 空间浏览：目录树、方块图、详情；按目录 / 按归属 / 按类别汇总；142 条内置规则说明每个位置是什么、归哪个软件、删了有什么影响。
- 快照与增长：扫描后自动保存快照（也可以每天定时），看哪些目录在变大、按这个速度多少天写满。
- 清理：按风险分组的清理计划，确认后删除或运行官方清理命令（uv、npm、pip、dotnet nuget 等）；也可以只打开所在位置自己处理，再重新测量。
- 操作记录：每次删除、运行命令、手动清理、拦截都记下来，只追加不修改，可以导出 CSV。
- 设置：每日快照、快照阈值和保留时长、临时文件的最小年龄、被占用文件的处理、追加自己的保护目录。

## 安全

- 删除是永久的，不经过回收站。执行前先显示确认框，列出删除后无法恢复的内容。
- 凭据、浏览器登录数据、程序和系统目录在内置保护名单里，任何规则都不能清理；可以追加自己的保护目录。
- 执行前逐项复核：路径上不能有 junction 或符号链接、再查一次保护名单、规则仍然命中；不跟随链接；被占用的文件跳过，不强制结束程序。
- 用另一个管理员账户提权时，不清理用户目录、不运行命令。

## 已知问题

- 写入监控（是谁写的）和 AI 分析在后续版本提供，设置页里显示为"后续版本"。
- 普通权限的遍历扫描识别不了硬链接，预计释放可能偏多；以管理员身份扫描更准确。
- 这个版本还没有在干净的 Windows 10 / 11 虚拟机上走过一遍，只在开发机（Windows 11）上验证过。
