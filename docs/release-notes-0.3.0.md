# DiskThinner 0.3.0

新增可选安装的常驻监控服务：开机后自动记录哪个程序在写磁盘，不需要一直开着 DiskThinner。只在本机运行，不联网。

## 下载哪个

| 文件 | 说明 |
|---|---|
| `DiskThinner-0.3.0-win-x64.zip`（约 4.8 MB） | 需要先装 [.NET 10 桌面运行库（x64）](https://dotnet.microsoft.com/download/dotnet/10.0)。没装时双击会提示去下载 |
| `DiskThinner-0.3.0-win-x64-selfcontained.zip`（约 48 MB） | 单个 exe，不需要装运行库 |

解压到任意目录，运行 `DiskThinner.exe`。支持 Windows 10 / 11 64 位。从 0.2.0 升级：直接用新目录替换旧目录，`%LOCALAPPDATA%\DiskThinner` 下的设置、快照、写入监控数据和操作记录照常可用。两个包里都有 `Agent\` 目录（常驻服务的程序），不装服务时用不到它。

## 新功能：常驻监控服务（可选）

- 在"设置 → 写入监控"里选"常驻服务"，点"安装…"。安装前的对话框说明服务做什么、装在哪、数据在哪、开销多大；确认后复制程序、注册并启动服务，几秒完成。需要管理员权限，普通权限下按钮是"以管理员身份重启并安装"。
- 服务名 `DiskThinnerAgent`（显示名"DiskThinner 写入监控"），以 SYSTEM 身份运行，开机自动启动（延迟），出错时 1 分钟和 5 分钟后各自动重启一次。被别的程序停掉记录时，1 分钟后重新开始。
- 记录的内容和临时诊断一样：哪个程序在哪个目录新建、删除、重命名、写入了文件，按"目录 × 进程 × 小时"汇总，不记录文件名和文件内容。结果显示在增长分析、概览和空间浏览里，和临时诊断的数据合在一起；会话表里标"常驻"。
- 服务在记录时：
  - 工具栏显示"写入监控：常驻（精确）· 已记录 N 天"；
  - "开启诊断"换成"常驻服务正在记录"，不再开第二个会话。
- 安全：
  - 服务程序复制到 `C:\Program Files\DiskThinner\Agent\` 再运行（复制后核对 SHA-256），不从解压目录运行；
  - 数据在 `C:\ProgramData\DiskThinner\Agent\`，只有 SYSTEM 和管理员能访问；
  - 界面经本机的命名管道查询，普通用户看不到其他用户个人目录下的记录，也不能停止或修改服务；
  - 服务只写自己的数据目录，不联网，不打开被写入的文件，不删除任何文件。
- 开销：本机实测空闲 30 分钟，CPU 约 0.09%，内存约 50 MB，没有丢事件。
- 数据默认保留 90 天，另有 256 MB 的上限。记录模式和保留天数在设置里改（需要管理员）。
- 停止、启动、更新、卸载都在设置里。卸载时可以选择是否同时删除已经记录的数据，默认保留，重新安装后接着用。升级 DiskThinner 后，设置里会提示"更新服务"。
- 规则和推断都不认识的目录：常驻服务记录满 7 天、主要写入程序占这里增长的 80% 以上时，归属显示为"实测：写入程序（顶层应用）"，标签是"实测"。只作为参考，不改变类别、风险和清理计划。
- 命令行：`DiskThinner.exe agent --install | --update | --uninstall [--delete-data] | --status`，用法见 README。

## 其他改动

- 临时诊断和常驻服务都直接调用 Windows 的 ETW 接口，不再依赖 TraceEvent。
- 精确模式下，"关闭时删除"的临时文件在会话结束时一定按删除计算，不会误算成增长。
- 设置页"保留"一行同时显示诊断数据和常驻服务数据的占用。

## 已知问题

- 服务停止时，界面看不到它记录的数据（数据目录只有管理员能读，界面只经管道查询）。
- 常驻服务的数据里，"关闭时删除"的临时文件最长要一天才按删除计算，在这之前会先显示为增长。
- 关机时服务的最后一次落盘、睡眠唤醒、另一个普通用户登录后的查询，还没有实机测过（单元测试和测试服务覆盖了）。
- 冷启动到窗口显示约 1.7 秒，没有达到 1 秒的目标（已确认和 TraceEvent 无关）。
- 发布前在全新的 Windows Server 2022 和 2025（GitHub Actions）上做过冒烟测试，两个包的扫描、快照、写入监控、常驻服务的安装、查询和卸载都正常。还没有在干净的 Windows 10 / 11 桌面版上走过一遍。
- 没有代码签名，下载后 Windows SmartScreen 可能提示"未知发布者"；杀毒软件对"安装 SYSTEM 服务"的反应只在 Windows Defender 下看过（没有提示）。

完整的已知问题见仓库里的 `docs/known-issues.md`，阶段 2b 的验收结果见 `docs/phase2b-report.md`。
